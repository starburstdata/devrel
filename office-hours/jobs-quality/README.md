# jobs-quality

## Office Hours: Pipeline Automation and Data Quality

### [Watch On-demand](https://www.starburst.io/info/office-hours-pipeline-automation-and-data-quality/)

### Description

This 30 minute Office Hours interactive & hands-on webinar walks through how to automate your data pipelines with the SQL job scheduler so they run reliably at scale. Additionally, we explore the data quality checks available. We implement multiple checks and review them on the monitoring dashboard.
