# access-controls

## Office Hours: Secure Data Access with ABAC, RBAC, and Fine-Grained Controls

### [Watch On-demand](https://www.starburst.io/info/office-hours-abac-rbac-fine-grained-controls/)

### Description

This 30 minute Office Hours interactive & hands-on webinar shows how to lock down access to sensitive data across all your sources with a unified policy layer using classical RBAC and tag-based ABAC plus row-level filtering and column masking.
