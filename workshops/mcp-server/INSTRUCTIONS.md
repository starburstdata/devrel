# Workshop Instructions: MCP Server - Building Your Agent with Starburst

This document contains the step-by-step instructions needed to complete the [MCP Server - Building Your Agent with Starburst](./README.md) workshop.

## Starburst Galaxy setup

If you do not already have a configured Starburst Galaxy environment, please [sign up](https://www.starburst.io/free-trial/) now. As you can see in this [YouTube short](https://www.youtube.com/shorts/rel2EMmxR9c), it really is quick & painless.

## Claude setup

If you do not already have a Cloud account, please [sign up](https://claude.ai/) now. There is a FREE tier and you only need to have Claude working in your browser (no need to download Claude Desktop or use Claude Code).

## Leverage tutorial for hands-on activities

The [Integrate Starburst Galaxy MCP with Claude Desktop](https://devcenter.starburst.io/tutorials/integrate-starburst-galaxy-mcp-with-claude-desktop) tutorial contains the steps we will go through together to setting up an OAuth client, connecting with the MCP Server, and performing natural language analysis. Despit the name of the tutorial, the activities can be completed in the browser interface and you do not need to install Claude Desktop.
